# Stage 2 — Creative Evaluation and Retry-Workflow Research

**Status:** Not started
**Phase:** Research only

Read the completed Stages 0–1 record and research/stages/stage-02-user-research.md completely.

## Objective

Determine the smallest defensible method for comparing creative outputs and recording retries without pretending subjective judgment is objective.

## Research questions

1. Which output properties can be checked deterministically from local image or video metadata?
2. Which creative qualities require a human judgment?
3. How should a single evaluator compare attempts without producing a false universal model ranking?
4. What minimum failure taxonomy is useful for image/video generation?
5. Which attempt, credit, time, and edit fields can support a bounded decision?
6. When do blind ordering, randomization, multiple raters, or statistical measures become necessary—and therefore remain out of the minimum artifact?
7. How should the record distinguish failed render, rejected output, near miss, accepted candidate, and later edit?

## Method

- Prefer primary research, official evaluation guidance, standards, and documented practitioner methods.
- Separate general evaluation practice from any claim about HexCoded.
- Compare the proposed method with one spreadsheet-based workflow.
- Keep the rubric fixed and short unless evidence requires otherwise.
- Do not automate aesthetic, likeness, safety, legal, or rights judgments.

## Required output

Record one minimum evaluation workflow, objective checks, human rubric, failure tags, calculation definitions, bias/limitation notes, and the spreadsheet comparator in implementation/cumulative-report.md. Update implementation/handoff.md.

Do not write application code.

## Exit gate

Continue only if the method produces a useful per-brief decision record without claiming general model performance.
